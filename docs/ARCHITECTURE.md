# 架构说明

## 分层

- `src/core.py`：路径、预设、状态、历史、TOML 文本改写和原子文件操作。
- `src/connection.py`：受限的模型列表和模型调用测试。
- `src/userenv.py`：Windows 当前用户环境变量的读取、事务写入和广播。
- `src/app.py`：CLI、pywebview API 桥接、后台任务和一次性确认令牌。
- `src/ui.py`：内联 HTML/CSS/JavaScript，不直接接触文件系统或注册表。

核心层不依赖 GUI，GUI 和 CLI 共用同一套业务逻辑。

## 配置切换

切换当前预设的基本流程：

1. 检测 Codex/宿主程序是否仍在运行。
2. 读取 `.state` 中记录的当前预设。
3. 将当前 `config.toml` 逐字节回收到该预设，并创建历史备份。
4. 将目标预设原子复制到 `config.toml`。
5. 原子更新 `.state`。

编辑当前预设时同样遵循“先回收，再修改，再同步当前配置”，防止下次切换将编辑结果覆盖。

## TOML 保真策略

本项目不把整个 TOML 解析成字典后重写。编辑器只替换目标键所在行，缺失键按所属段插入，并保持：

- 注释
- 键顺序
- 未识别段
- 多行数组和多行结构
- CRLF/LF 换行风格

往返保真测试要求：提交一份与当前值完全相同的表单后，输出必须与源文件逐字节一致。

## 文件安全

- 写入使用临时文件、刷新后原子替换。
- 恢复历史版本前先备份当前目标。
- 历史恢复使用短期 opaque ID，并在执行前复核路径、大小、时间和 SHA-256。
- 配置删除前创建历史备份；当前正在使用的预设不可删除。
- 所有名称和用户路径都经过严格校验。

## 密钥安全

- TOML 只保存环境变量名。
- API Key 写入 `HKCU\Environment`，失败时回滚配置和环境变量。
- 未保存的密钥仅在进程内存中使用。
- 网络操作使用短期一次性令牌，绑定操作类型、主机、模型、协议和密钥摘要。
- 错误、日志、差异和诊断结果会进行脱敏。

用户环境变量不是加密存储，同一用户上下文内的其他程序通常可读取。

## 网络边界

- 默认只允许 HTTPS；仅回环地址允许 HTTP。
- TLS 验证开启。
- 不跟随 HTTP 重定向。
- 设置超时、响应体大小、模型数量和字符串长度上限。
- 不自动重试模型调用。
- 官方登录令牌不由本工具读取或管理。

## 测试隔离

测试必须使用临时 `CODEX_HOME`、临时 settings 和假密钥。默认不读取真实用户配置；显式设置 `CODEX_REAL_CONFIG_SMOKE=1` 才允许只读哈希冒烟检查。网络测试仅使用本地 mock 或 monkeypatch。
